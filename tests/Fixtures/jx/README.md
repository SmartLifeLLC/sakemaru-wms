# JXテスト用資料と固定データ

`*_sample.txt` は既存の次のアーカイブから、バイト列を変更せずに複製した参考資料です。

`storage/specifications/old/ordering/ordering/done/old/`

作成日・提供元は未確認です。資料の改行や値をそのまま本番の正しい出力仕様とは扱いません。
1017・1106・1202・1330の4送信先のレコード構造・フィールド位置を確認するために使用します。
SHA-256とレコード数は `JxTestRecordsTest::archives()` で固定し、意図しない資料変更を検出します。
`.gitattributes` の `-text` により、Shift_JISのバイト列と元の改行を保持します。

## 読み取り方針

- 参考資料だけは、128バイトのレコード境界にあるLF／CRLFを許容します。
- レコード内の改行、途中で切れたデータ、不正な区分、余分な空行はエラーにします。
- 生成データは別の厳格な読み取りを使い、内部改行は許容しません。
- 資料がない場合は、スキップせずファイルパス付きのエラーにします。
- 実行ディレクトリやアーカイブの配置に依存しない絶対パスで参照します。

## DBデータと出力の基準

`Tests\Support\JxGeneratorTestCase` が、各試験専用のSQLiteメモリDBに合成データを作成します。
業務DBや既存候補・マスタには接続しません。試験終了時に接続と固定時刻を破棄します。
SQLのREGEXP／LPAD互換関数は読み取りクエリ用で、MySQLのロックや性能の検証を代替しません。

`generated/*.dat` は、この固定データと固定時刻 `2026-08-17 10:15:00`、
`FakeLegacyEosSlipNumberService` の初期連番18628を使い、修正前の
`release/v1.0`（`c044fc0186552755f3f1f85d831dcfb600037462`）の生成クラスで出力したものです。
実際の顧客発注データではありません。4送信先への集約を含め、バイト単位の回帰を検出します。
JX設定も合成データであり、開始・終了レコードを含む出力全体を比較します。
期待ファイルを更新する場合は、固定データや仕様の変更理由と変更前後の差を確認してください。
失敗した現在の生成結果をそのまま期待ファイルへ上書きする運用はしません。

## 実行

```sh
composer test:jx
```

資料・生成テストと、採番・取消・生成失敗後の回復・通常登録画面の既存回帰テストを実行します。
失敗・スキップ・警告・risky・PHPUnitの非推奨があれば終了コードを失敗にします。
DB不足を理由とするスキップ分岐は設けません。対象の旧テストの `@test` は属性へ移行しています。
従来スキップされていた文字コード検証の期待値は、現行の生成クラスが返す `SJIS-win` に合わせています。
生成処理や出力バイト列を変更するものではありません。
